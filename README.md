# Lite Browser (Android)

مرورگر سبک اندروید بر پایه Android System WebView (موتور Chromium)، بدون هیچ کتابخانه خارجی.

## ساخت APK با GitHub Actions
1. محتویات پروژه را در یک ریپوی جدید گیت‌هاب پوش کنید.
2. تب **Actions** ← ورک‌فلو **Build Android APK** (با هر push خودکار اجرا می‌شود).
3. در پایان از بخش **Artifacts** فایل `LiteBrowser-APK` (شامل debug و release) را دانلود کنید.
